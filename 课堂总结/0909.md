课程内容：计算机网络概述
移动通信网络架构：从3G/4G到5G
本次课程以一个具体的网络实例——移动通信网络（3G/4G/5G）作为切入点，通过分析其结构来引出计算机网络的核心概念。移动通信网络的代际划分（Generation，如4G中的“G”）主要取决于其数据传输能力，其设计目标经历了从话音业务到数据业务的根本性转变。最初的设计完全面向话音，而如今数据业务已成为绝对主流，话音业务退居其次。

整个移动通信网络可以清晰地划分为三个层次：移动台子系统、无线接入网（RAN， Radio Access Network）和核心网（CN， Core Network）。

移动台子系统
这层最接近用户，包含两类设备。第一类是移动设备，如手机、平板电脑、智能手表等。其名称经历了从MS（Mobile Station）到UE（User Equipment）的演变。每个移动设备都有一个全球唯一的标识符，即IMEI（International Mobile Equipment Identity）。第二类是SIM卡，它作为用户身份的标识，用于运营商计费和认证，其标识符为IMSI（International Mobile Subscriber Identity）。

无线接入网
无线接入网负责将移动设备通过无线方式接入网络，同样包含两类关键设备。第一类是基站（Base Station, BS），其专业术语在不同代际中有所变化，3G时代称为Node B，4G时代称为eNode B（evolved Node B），5G时代则进一步演变为gNode B（next generation Node B）。基站的覆盖范围从几百米到几十公里不等，它通过无线链路与移动设备通信，这条链路有一个专业术语叫空中接口（Air Interface），业界常简称为“空口”。空中接口是整个移动通信网络代际演进中变化最大、竞争最激烈的部分，因为它直接决定了网络带宽和速率。例如，3G网络的理论最高速率约为1 Mbps，而2G只有几十到几百Kbps，瓶颈就在于此。

第二类设备是无线网络控制器（RNC， Radio Network Controller）。一个RNC可以控制多个基站。值得注意的是，从RNC再往核心网方向，全部采用有线网络，因为有线网络比无线网络更稳定、出错率更低且易于恢复。

核心网与互联网接入
核心网是网络的“大脑”，包含分组域和电路域。在核心网中，RNC连接到SGSN（Serving GPRS Support Node），一个SGSN可以控制多个RNC。SGSN是服务GPRS支持节点，这里的GPRS（General Packet Radio Service）代表无线分组交换网络。SGSN再连接到GGSN（Gateway GPRS Support Node），一个GGSN可以控制多个SGSN。在4G/5G时代，这些设备名称演变为SGW（Serving Gateway）和PGW（Packet Data Network Gateway）。GGSN/PGW作为一个网关（Gateway）设备，其核心作用是进行协议转换和翻译，使得4G/5G网络内部的数据能够顺利进入并融入互联网。整个运营商的网络，如上海移动的网络，最终作为一个子网，通过此关口接入到全球互联网中。

此外，核心网中还包括许多其他重要设备，例如负责认证的服务器（如RADIUS），用于验证用户身份和权限，确保不同套餐的用户获得相应的服务；以及计费系统，用于采集用户的流量使用数据，进行计费。核心网在逻辑上分为电路域（Circuit Domain）和分组域（Packet Domain）。电路域由一系列移动交换中心（MSC， Mobile Switching Center）组成，通过电路交换机处理话音业务，其设计思想起源于传统的电话网络。分组域则是我们关注的重点，它基于分组交换技术处理数据业务。

研究案例：网络数据采集与分析
课程中分享了一个基于此架构的研究案例。研究团队在SGSN和GGSN（或SGW和PGW）之间的接口上部署设备，实时采集用户数据，并进行分析。这项工作面临两大挑战：第一，数据流量巨大，必须解决高速抓包不丢包的问题；第二，用户的一次完整上网过程（一次“会话”，从接入到离开）会跨越多个数据采集文件（如每个文件500MB），并且数据包经过多层协议封装，甚至在SGSN-GGSN之间存在隧道协议（Tunnel Protocol），因此需要逐层解析头部，并还原出用户的完整会话轨迹。基于这些分析，研究团队可以为运营商提供网络性能（如吞吐量、时延、丢包率）测试，以及网络安全分析，例如观测是否存在由于数据业务模式不当而引发的“信令风暴”，导致控制平面资源耗尽，或是检测恶意应用窃取用户隐私的行为。

计算机网络的核心教材与课程定位
本课程采用的主要教材是James Kurose和Keith Ross的《计算机网络：自顶向下方法》。该教材在北美高校中使用率极高，其特点是自顶向下（Top-Down Approach），即从应用层开始讲起，再逐步深入到传输层、网络层和链路层。这与传统的自底向上（从物理层开始）的讲授方式截然不同，使得学习过程更容易入门，但其内容对复旦大学学生而言可能偏简单。另一本重要参考书是Larry Peterson和Bruce Davie的《计算机网络：系统方法》，这本书从网络设计者的视角出发，深入探讨了网络设计中的需求和方案，并会详细介绍历史上的各种研究方案，更适合有志于从事研究的学生，也是CMU等顶尖高校的教材。这两本教材之所以成为经典，是因为计算机网络作为一门学科，其核心内容已相当固定，最活跃的研究时期（如网络互联）集中在20世纪70至80年代。

分层思想与网络抽象
分层是计算机网络设计的核心思想，其本质是抽象（Abstraction）。通过分层，一个复杂的网络系统被逻辑上分割为若干个相互独立的模块（实体），每一层实体利用下层提供的服务，并向上层提供更高级的服务，而下层服务的具体实现对上层而言是透明的（即“黑盒”）。

以一个简单的网络聊天程序为例，程序员只需调用操作系统提供的Socket接口，即可方便地实现两台主机间的通信，而无需关心底层是如何将文本编码为二进制信号、如何进行物理的基带信号传输、如何解决共享链路的冲突等一系列复杂问题。这些底层细节被一步步抽象并封装在了不同的网络层次中。

数据传输中的加头与去头过程：当数据从源主机的高层向低层传递时，每一层都会在数据前面加上该层的头部（Header），这个过程称为“封装”。头部包含了该层的控制信息，也称为信令（Signaling）。当数据到达目标主机，会从低层向高层进行“解封装”，即层层去掉头部，最终将原始数据交给应用层。例如，一个Web页面数据，会先加上HTTP头部，再依次加上TCP头部、IP头部和链路层头部。在源主机是“层层加头”，在目标主机则是“层层去头”。一个常见的概念混淆是搞错哪个头部在最外层，在发送时，最底层的头部在最前方。

头部（信令）的本质与随路/共路信令：头部的本质是“控制”或“信令”。网络设计中的一个首要问题是处理控制（信令）与数据的关系。这方面存在两种截然不同的设计理念。
* 共路信令（Common Channel Signaling）：以传统电话网络（PSTN）为代表。在这些网络中，控制信息和话音数据在物理上是分离的，有专门的信令网负责在通话前协商好路径，而话音数据则直接通过交换机矩阵传输，不携带任何控制头部。
* 随路信令（In-band Signaling）：以互联网为代表的计算机网络采用了完全不同的思想。每个数据包都自带控制头部，即数据包自己携带寻址和转发所需的所有信息。这背后的根本原因是计算机网络所基于的分组交换（Packet Switching）思想。分组交换最早由美国国防部高级研究计划局（ARPA）资助的网络研究提出，其设计初衷是为了应对核战争场景下的网络生存性。在分组交换网络中，每个数据包可以独立地在网络中寻找路径，即使某些节点被摧毁，数据包仍能通过其他路径到达目的地，因为每个数据包都“知道”自己要去哪里，而无需依赖一条集中控制、可能随时中断的信令链路。这种设计是计算机网络区别于传统电信网的一个根本性变化。

控制平面的抽象与软件定义网络（SDN）
从20世纪70年代到80年代，计算机网络领域完成了对数据平面（Data Plane）的抽象，形成了OSI七层模型和TCP/IP五层模型这两个经典的分层架构。然而，随着网络规模和应用复杂性的增加，到21世纪初，控制平面（Control Plane）的僵化问题逐渐凸显，成为网络发展的瓶颈。

传统网络中的分组交换机（如路由器）是独立工作的，每个设备都有自己的控制平面，根据各自的路由算法独立决定数据包的转发路径。这种分布式控制方式使得网络管理员难以进行全局的流量工程（Traffic Engineering），即无法灵活地控制和优化整个网络的流量走向。

为了应对这一挑战，大约从2006年开始，计算机网络领域兴起了对控制平面抽象的研究，其核心成果是软件定义网络（SDN， Software Defined Networking）。SDN的核心思想是将控制平面与数据平面分离。
* 传统网络：每个交换机包含专用硬件和嵌入式操作系统，控制逻辑和转发功能紧密耦合在一个封闭的盒子中。
* SDN架构：采用一个逻辑上集中的控制器（Controller）来管理整个网络。控制器运行网络操作系统，拥有全局网络视图，并向上层应用（如路由计算、访问控制、流量工程等）提供可编程的API（北向接口）。控制器通过控制协议（如业界标准的OpenFlow协议，南向接口）向底层的标准化交换机下发流表，精确控制每个数据包的转发行为。交换机变为只负责高效数据转发的“白盒”设备。这使得网络变得可编程、更灵活，能够像管理一个单一系统一样管理整个网络。SDN是自2000年以来计算机网络领域继分层模型之后，又一次重大的体系结构变革，它在一定程度上“颠覆”了传统计算机网络“随路信令”的设计思想，在更高的层面上重新引入了“共路信令”的集中控制逻辑。

网络的基本构成与复用概念
从抽象的角度看，一个计算机网络可以定义为由一系列相互连接的自治系统组成的集合。其基本构成要素可以抽象为：端系统（End System） + 链路（Link） + 交换节点（Switching Node）。在互联网的具体实例中，它们分别对应主机（Host）、链路和路由器（Router）。

网络拓扑的演进：
* 最简单网络：两台主机通过一条链路直接相连。此时主要关注链路层问题，如物理信号、编码、介质访问控制等。
* 总线型网络：多台主机通过一条共享总线相连（如早期的以太网）。这种结构存在严重的可扩展性（Scalability）问题，因为所有主机共享同一通信介质，同一时刻只能有一台主机发送数据，效率低下。
* 全连接网络：任意两台主机之间建立一条专有链路。这种方式需要  条链路，成本过高，同样不具有可扩展性。
* 星型网络：引入一个中心交换节点，所有主机通过各自链路连接到该节点。由交换节点负责数据的转发。这种结构大大减少了链路数量，是现代网络的基础拓扑。

复用（Multiplexing）：引入交换节点的核心目的之一是实现复用，即让多个用户共享同一网络资源（如一条链路）。例如，在星型网络中，连接交换机的某条链路可以被多个用户的数据流共享。共享的方式主要有时分复用（Time Division Multiplexing），即不同用户在时间上轮流使用该链路；以及频分复用（Frequency Division Multiplexing），即不同用户使用链路的不同频率资源进行通信。复用是贯穿计算机网络各层的一个核心概念。

互联网的定义：网络的网络
互联网（Internet）从构词法上理解，其本意是“网络的网络”（network of networks）。它不是指一个单一的网络，而是将全球范围内成千上万个由不同组织（如地区ISP、企业、学校、移动运营商）管理和运营的网络，通过路由器等设备相互连接起来而形成的超级网络。这是一个关键概念，例如，一个移动4G/5G网络是作为一个整体，通过网关设备接入到互联网中的。互联网上运行着无处不在的协议，如HTTP、TCP、IP、WiFi、4G/5G、Ethernet等，这些协议控制着消息的发送和接收。互联网标准由IETF（Internet Engineering Task Force，互联网工程任务组）制定，并以RFC（Request for Comments，请求评论）文档的形式发布。
