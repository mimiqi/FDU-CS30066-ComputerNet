## 来源的用途与可信边界

本目录以 Winter 2024 Minnow 的八个阶段为阅读主线。讲义说明任务要求，协议标准解释通用规则，原作者笔记和公开实现帮助比较解法。公开实现不是课程标准答案，其注释、性能和“通过测试”的自述不等于本次已经验证。

目前本地只有 [本校 Checkpoint 0 讲义](../check0/check0.pdf) 可直接核对。涉及课程实际提交、接口签名、测试目标和环境要求，应以本校后续讲义及拿到的 starter 为准。

## 协议与工具原始资料

| 资料 | 用途 |
| --- | --- |
| [RFC 9112：HTTP/1.1](https://www.rfc-editor.org/rfc/rfc9112.html) | HTTP 报文格式、行结束和连接语义 |
| [RFC 9293：TCP](https://www.rfc-editor.org/rfc/rfc9293.html) | TCP 序列号、确认、SYN/FIN 和窗口 |
| [RFC 6298：TCP 重传计时器](https://www.rfc-editor.org/rfc/rfc6298.html) | 理解真实 TCP 的 RTO；实验通常使用简化模型 |
| [RFC 826：ARP](https://www.rfc-editor.org/rfc/rfc826.html) | 地址解析请求和应答 |
| [RFC 791：IPv4](https://www.rfc-editor.org/rfc/rfc791.html) | IPv4 头部和 TTL |
| [RFC 1812：IPv4 路由器要求](https://www.rfc-editor.org/rfc/rfc1812.html) | 转发行为、TTL 与校验和等背景 |
| [Linux TUN/TAP 文档](https://docs.kernel.org/networking/tuntap.html) | 用户态程序如何接入虚拟网络设备 |
| [ping(8)](https://man7.org/linux/man-pages/man8/ping.8.html) | 采样间隔、序列号、输出及统计选项 |
| [CMake 命令行说明](https://cmake.org/cmake/help/latest/manual/cmake.1.html) | 配置和构建项目 |
| [CTest 命令行说明](https://cmake.org/cmake/help/latest/manual/ctest.1.html) | 枚举并执行测试 |
| [GNU SHA-2 工具说明](https://www.gnu.org/software/coreutils/manual/html_node/sha2-utilities.html) | 用 sha256sum 比较传输前后的文件 |

RFC 描述通用协议，实验讲义规定评分范围。比如本实验 ARP 的 5 秒请求间隔、30 秒缓存寿命属于课程模型，不能写成 RFC 强制常量。

## 在实验机上需要补充的证据

本次核验的是资料，不包含运行实验。实际完成时，在自己的报告中记录 starter 的来源和提交、系统与编译器、运行命令、测试输出、失败修复过程，以及测量数据、抓包或文件校验值。参考作者的输出不能用作自己的实测结果。
