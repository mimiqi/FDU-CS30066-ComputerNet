## 建议阅读顺序

1. 读本地 PDF，再看版本对照，明确需要完成的项目。
2. 用 HTTP 和终端通信笔记理解“通过 TCP 传送字节”的过程。
3. 获取课程 starter 后，阅读 `util/socket.hh`、`util/file_descriptor.hh` 的公共接口。
4. 对照 ByteStream 笔记理解接口语义，再自行实现和验证。
5. 使用构建调试笔记保存实际输出、失败原因和修复过程。

资料中的命令用于之后的 Linux 实验环境；本次整理没有运行实验测试。来源链接和检索状态集中记录在来源索引，网站内容之后可能更新。
